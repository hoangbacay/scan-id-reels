# scan-ID-Reels

Công cụ dòng lệnh dùng Playwright để thu thập ID Reels. Xem [hướng dẫn sử dụng](HUONG_DAN.md) để cài đặt Chromium và chọn khoảng ngày.

Chạy `npm test` để kiểm tra bộ lọc ngày cục bộ. Trước khi xuất bản, dùng `npm run review` hoặc `push.bat` trên Windows để xem trạng thái Git và thống kê diff. Xem nội dung diff, chọn tệp cần stage và chờ phê duyệt trước từng thao tác commit và push.
