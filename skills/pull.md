# Kỹ năng Pull Code từ GitHub

Khi người dùng chọn hoặc chạy kỹ năng này, bạn hãy thực hiện các bước sau:
1. Tự động chạy lệnh terminal: `npm run pull` để kéo tất cả các thay đổi và cập nhật mới nhất từ kho lưu trữ GitHub về máy tính của người dùng.
2. Thông báo kết quả cập nhật (danh sách các file thay đổi nếu có) cho người dùng ngay trong khung chat.
